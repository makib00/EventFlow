# EventFlow - Project Idea

**Name
EventFlow -  Event Registration Website

**Problem and goal
Small groups often use emails or spreadsheets to collect event registrations. It is hard to know how many places are left.

EventFlow puts events and registrations in one place. It is for free workshops and small events.

**Users
- **Visitor (participant): sees events and registers without an account.
- **Organizer: creates events and checks registrations.
- **Admin: manages organizer accounts.

**How it works
1. An organizer logs in and creates an event with a date, place, and capacity.
2. A visitor opens the event and enters a name and email address.
3. The system checks for free places and duplicate registrations.
4. If the registration is valid, the system saves it and shows a success message.
5. The organizer can see the registration list and cancel a registration.
