
# ADR 0003 - User Login

** Status
Accepted

** Context
Organizers and admins need secure access. Visitors should register for events easily.

** Alternatives
- All users must create an account.
- Only organizers and admins need an account.

** Decision
Only organizers and admins log in. Visitors can register for events without an account.

** Consequences
- Positive: Event registration is simple for visitors.
- Negative: Visitors cannot manage registrations through a personal account.
